===================File Explanation===================

This file gives explanations of the output files generated by TANDEM for each job.


SAVs.txt : Submitted SAV list used for this job.
  SAV is Single Amino acid Variant in format (UniProt_ID)(space)(WT_AA|ResidueID|Mutant_AA)

Uniprot2PDB.txt : Mapping between each SAV and the structure position used for feature extraction.
  - SAV : Input SAV.
  - pdbid/chid/resid/aa : Selected structure ID, chain ID, mapped residue index, and mapped amino acid.
  - resolved_len/total_len : Number of resolved residues over total residues for that mapped structure chain.

features.csv : Final per-SAV feature matrix used by model inferencing/transfer-learning.
  Each row is one SAV; columns are TANDEM input features (sequence/structure/dynamics-derived).

Main_Predictions.csv : Main prediction output table.
  Each row is one SAV; columns report model prediction values and classification summaries.

log.txt : Execution log for this job (steps, timings, warnings, and errors).
params.json : Job parameter snapshot stored by the worker (mode, SAV/model/STR, status, timestamps).

loss.png : Training/validation loss curve for transfer learning jobs.
test_evaluation.csv : Aggregated test metrics summary for TANDEM and TANDEM-DIMPLE.
test_evaluation.json : Per-run raw test metrics before aggregation.
cross_validation_SAVs.json : Cross-validation SAV split definitions (train/val/test per fold).
shap_background.npy : SHAP background array saved for explainability calculations.

tandem_shap/ : Per-SAV SHAP plots for TANDEM outputs.
tandem_dimple_shap/ : Per-SAV SHAP plots for TANDEM-DIMPLE outputs.
TD_*/ : Cross-validation fold directories containing model_*.h5 and history_*.csv files. (TD: TANDEM-DIMPLE)
